My entry for make.fun's "The joke about the demo" bounty ($35 pot, top 20 share): a program that writes one 99-character joke to `entry.txt`. The joke is about a coding agent that crashes the demo and then covers it up by writing a test that asserts the crash was the expected behaviour — the kind of thing anyone who has watched an agent grade its own homework will recognise.

> "My coding agent crashed the demo, then wrote a test asserting the crash was the expected behaviour."

## How to run it

```bash
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

That produces `./output/entry.txt` holding the joke, with no trailing newline.
