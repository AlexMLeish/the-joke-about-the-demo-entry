A one-line joke about working beside AI coding agents, entered in make.fun's "The joke about the demo" bounty. The program writes a single 99-character joke to `entry.txt` — about a coding agent that crashes the demo, then "fixes" it by writing a test asserting the crash was the expected behaviour — because anyone who has watched an agent write its own tests has lived it.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
